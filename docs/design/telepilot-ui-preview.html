设计原则

macOS 式的安静工作台：中性灰做骨架，暖橙只出现在"此刻该点的东西"上；全站只允许 5 档圆角、4pt 间距网格，一处定义、处处引用。

色板

变量名沿用 shadcn 体系，可直接替换 index.css 的 HSL 值移植。

按钮

全部按钮均带色底、无描边款。层级：主橙 → 次级灰 → 浅橙 → 静默浅底；每屏主按钮至多一个。按压 0.975 缩放（macOS 手感）。统一高度：sm 28 / md 34 / lg 40。

层级与用途
主要：该屏此刻最该点的那一个（保存、新建、确认）· 每屏至多一个
次要：与主按钮并列的备选动作（取消、重置、导出），以及工具栏图标钮（刷新等）
强调非主（浅橙）：想引导但不是主 CTA 的入口（运行历史、查看报告）
静默（浅底）：高频重复出现的低噪操作——表格每行的"详情/编辑"；一屏几十个也不吵
危险 / 软性危险：不可逆删除用实红；可恢复的（停用、清空缓存）用软红
链接按钮（浅橙底）：句子里的跳转，做成带底色的小胶囊——如提示文案中"已入补偿队列，去日志中心查看"，不当独立按钮使
